## 关于我们

farfarfun 主要维护小而实用的 Python 项目，覆盖云存储、文件传输、数据存储、密钥管理和开发工具等场景。各项目独立安装、独立发布，具体兼容版本与用法以项目 README 为准。

## 核心项目

| 项目 | 用途 | PyPI |
| --- | --- | --- |
| [fundrive](https://github.com/farfarfun/fundrive) | 使用统一接口操作多种云存储服务 | [![PyPI](https://img.shields.io/pypi/v/fundrive?style=flat-square)](https://pypi.org/project/fundrive/) |
| [funtable](https://github.com/farfarfun/funtable) | 为 SQLite、TinyDB、SQLModel 等后端提供统一表存储接口 | [![PyPI](https://img.shields.io/pypi/v/funtable?style=flat-square)](https://pypi.org/project/funtable/) |
| [nltget](https://github.com/farfarfun/nltget) | 支持并发、断点续传和命令行的 HTTP 文件传输工具 | [![PyPI](https://img.shields.io/pypi/v/nltget?style=flat-square)](https://pypi.org/project/nltget/) |
| [nltfile](https://github.com/farfarfun/nltfile) | 文件、归档与序列化实用工具 | [![PyPI](https://img.shields.io/pypi/v/nltfile?style=flat-square)](https://pypi.org/project/nltfile/) |
| [nltsecret](https://github.com/farfarfun/nltsecret) | 本地密钥管理与可选的 MySQL 同步 | [![PyPI](https://img.shields.io/pypi/v/nltsecret?style=flat-square)](https://pypi.org/project/nltsecret/) |
| [nltbuild](https://github.com/farfarfun/nltbuild) | Python 与混合项目的构建、发布和版本管理 | [![PyPI](https://img.shields.io/pypi/v/nltbuild?style=flat-square)](https://pypi.org/project/nltbuild/) |

更多项目可在 [Repositories](https://github.com/orgs/farfarfun/repositories) 中查看。

## 快速开始

选择项目后直接从 PyPI 安装，例如：

```bash
pip install fundrive
```
